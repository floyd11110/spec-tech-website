Resource ownership

Know what peripheral owns each pin and timer.

Resource ownership is explicit so reusable libraries do not silently fight over the same STM32 peripheral.

ResourcePrimary owner / useImportant rule
PA8 / TIM1_CH1Basic PWM, test signal sourceOne active owner at a time.
PA6 / TIM3Capture / SignalAnalyzer CapturePA6 is also SPI1 MISO; do not share it while Capture is active.
PA0 / TIM2Counter / SignalAnalyzer CounterConflicts with Basic TIM2 ownership and PA0 ADC while Counter is active.
PB6 / PB7I2C1 shared busDevice libraries share the SPEC-TECH I2C layer; unique addresses are required.
PA9 / PA10USART1 debug / FTDICommon debug and serial validation path.
PA13 / PA14SWDReserved for programming/debugging.

Release engineering

How a SPEC-TECH library becomes FINAL.

01

Design

Define purpose, API, pins, timers, dependencies, and conflicts before coding.

02

TEST FLAT

Active core development stays in a flat test folder while features are changing.

03

Hardware Regression

Run real-board tests, edge cases, restart/recovery checks, and resource cleanup tests.

04

RC Install

Install the packaged Arduino library and repeat the regression from the installed copy.

05

FINAL / FROZEN

Freeze the known-good version. Future behavior changes branch to a new version.
