Current development estimate

Basic PLC software core is approaching feature-complete status

The current software core is approximately 80–85% of the intended ST-CPU-MEGA Basic PLC software scope. The complete V1 product is approximately 70–75% when industrial 24 V I/O hardware, analog I/O, HSC, communications, final compiler hardening, and full release regression are included.

Current development directions: continuous timer/counter functions, numerical/math and compare operations, analog processing, ST Module Manager/API integration, edge contacts, HSC, communications, compiler hardening, and final stable-release testing.

Release engineering

How a SPEC-TECH library becomes a retained release.

01

Design

Define purpose, API, pins, peripherals, dependencies, and conflicts before coding.

02

TEST / Development

Develop the feature set without modifying an existing frozen known-good release.

03

Hardware Regression

Run real-board tests, edge cases, restart/recovery checks, and resource-cleanup tests.

04

Installed / Soak Gate

Repeat regression from the packaged library and run soak testing where appropriate.

05

STABLE / FINAL / FROZEN

Retain the known-good version. Future behavior changes branch to a new version.

Current STM32 development direction

Dual-signal timing foundation

The next planned timing work is a new TEST branch for synchronized two-signal timing, intended to support future phase, propagation-delay, edge-order, and dead-time analysis without modifying the frozen Capture or SignalAnalyzer releases.
