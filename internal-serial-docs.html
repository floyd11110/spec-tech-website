PHASE 3 / PERIPHERAL CONVENIENCE LAYER

STSerial v0.1.0-DEV

General serial convenience wrapper for the current Arduino Nano / ATmega328P checkpoint. It uses the normal Arduino HardwareSerial path and does not add a scheduler, interrupts, or background processing.

Basic use

#include <STSerial.h>

STSerial stSerial(Serial);

void setup()
{
    stSerial.begin(115200);
}

void loop()
{
}

API reference

FunctionPurposeStatus
begin(baud)Starts the selected HardwareSerial port and applies the configured timeout.PASS
available()Reports bytes waiting in the RX buffer.PASS
read()Reads one byte from the RX buffer.PASS
readLine(buffer,length)Reads until newline or timeout, null-terminates the result, and strips trailing CR from CRLF input.PASS
print(value)Forwards formatted output to HardwareSerial.PASS
println(value)Prints a value followed by a line ending.PASS
println()Prints only a line ending.PASS
printValue(label,value)Prints a simple LABEL=value record.PASS
clearInput()Drains all currently buffered RX bytes.PASS
setTimeout(ms)Changes timeout used by blocking stream reads.PASS

Blocking behavior

Important

readLine() uses a timeout-based stream read and can block until newline, buffer limit, or timeout. It is appropriate for simple interactive communication; a future framed/non-blocking parser should be a separate layer.

STSerial vs STSerialIO

LayerRole
STSerialGeneral serial communication helper for text, lines, bytes, values, and input-buffer management.
STSerialIOSpecialized I/O monitor protocol for reporting watched digital/analog state to the IDE monitor.
