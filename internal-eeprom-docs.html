PHASE 3 / NEXT VALIDATION TARGET

STEEPROM v0.1.0-DEV

Lightweight EEPROM convenience wrapper for the Arduino Nano / ATmega328P target. Implementation is ready for regression testing but is not yet marked hardware validated.

API

FunctionPurposeStatus
read(address)Reads one EEPROM byte.PENDING
write(address,value)Writes one EEPROM byte.PENDING
update(address,value)Writes only when the stored byte differs.PENDING
get(address,object)Reads a typed object/record.PENDING
put(address,object)Stores a typed object/record using Arduino EEPROM semantics.PENDING
length()Returns EEPROM capacity reported by the Arduino core.PENDING
validAddress(address)Checks whether an address is within the reported EEPROM byte range.PENDING

Regression design

The first packaged regression uses byte address 100 and structured-record address 110. It saves their existing contents, performs byte and typed-record tests, and restores the original data before completing.

EEPROM endurance

EEPROM has finite write endurance. The regression performs only a small controlled number of writes. Prefer update() when a byte may already contain the desired value.

Validation hardware

No external components are required: Arduino Nano, USB cable, PC, and ST Embedded IDE Serial Monitor are sufficient.
